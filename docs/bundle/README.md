## Recommended order of use

If you want to use all six over time:

1. **Month 0** — Budget Tracker only. Get income + fixed expenses + categories nailed down.
2. **Month 1** — Add Net Worth Tracker. Snapshot your starting balance sheet.
3. **Month 1-3** — If in debt: add Debt Payoff Planner. Run snowball + avalanche simulations.
4. **Month 2-4** — Add Sinking Funds Planner. Bucket your short-term goals.
5. **Month 3-6** — Add Investment Portfolio Tracker if you have brokerage accounts.
6. **Anytime** — Add Family & Education Planner if you have kids.

The Bundle Setup Wizard PDF (9 pages, finance) walks you through each step. Open it now.

## How the 6 SKUs connect (manual sync points)

This bundle was designed so each spreadsheet works independently. That means you'll see some numbers in two places. Keep them aligned manually at month-end:

- **Debt total** — same value in Debt Payoff Planner (Debt List total) and Net Worth Tracker (Liabilities Summary total). Update both when you make a payment.
- **Investment portfolio total** — Investment Portfolio Tracker → 🏠 Dashboard → Total MV. Copy that number to Net Worth Tracker → 💼 Assets Summary → Stocks & Funds (Taxable) row. Look for the 🔗 "BUNDLE NOTE" callout on that row.
- **FX rates** — both Net Worth Tracker (Settings & FX) and Investment Portfolio Tracker (Cash & FX Holdings) have foreign-currency rate tables. Update both with the same rates monthly. Look for the 🔗 "BUNDLE NOTE — FX rate sync" callout on each.
- **Sinking fund bucket totals** — sum of all sinking-fund buckets should approximately match the liquid-cash line in Net Worth Tracker. Update at month-end.
- **Savings rate** — Budget Tracker's "savings" rate should equal (sinking fund deposits + new investment money) ÷ income for the month.

A future version of the bundle may auto-link these numbers via Google Sheets cross-workbook references. The current Excel-native edition keeps each workbook independent.

Each SKU has its own quickstart PDF (1 page) and AI advisor PDF (8-12 pages of methodology + recommendations). Read your AI advisor PDF before customizing the spreadsheet for the first time — it explains the methodology and the trade-offs we picked.

If a formula breaks: download the workbook fresh from your Etsy "Files" tab — the original is always recoverable.

## Tier choices

Three tiers per SKU. They share the same core math; tiers differ in depth.

- **Essentials** — single-tab inputs, single-tab outputs. ~5 tabs. Best for "just give me the answer."
- **Pro** — multi-tab inputs, multiple methodologies (e.g., Snowball + Avalanche + Custom). ~12-15 tabs.
- **AI Edition** — Pro features + an AI Advisor tab with model-generated reasoning + a scenario simulator. ~17-21 tabs.

If you don't know which tier to use, start with **AI Edition** — you can ignore the AI tabs and the spreadsheet still works at Pro depth.
