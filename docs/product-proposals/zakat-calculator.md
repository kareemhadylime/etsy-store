## Sheet Tabs (18 tabs + AI tab + supporting tabs)

| Tab | Description |
|-----|-------------|
| 🏠 Dashboard | Total Zakatable wealth, Nisab status, Hawl status, Zakat due, payment status YTD, Zakat al-Fitr alert |
| ⚙️ Madhhab Settings | Hanafi/Maliki/Shafi'i/Hanbali toggle. Sheet adjusts ruling logic across all tabs |
| 📋 Wealth Inventory | Cash, gold, silver, foreign currency, refundable deposits, Hajj/Umrah savings, business inventory, receivables, insurance cash value (Takaful/whole-life) |
| ⚖️ Nisab Calculator | Gold (87.48g) vs. Silver (612.36g) toggle. Live gold/silver spot via GOOGLEFINANCE. Daily auto-update |
| 📅 Hawl Tracker | Per-account 12-month lunar anniversary. Hijri ↔ Gregorian conversion. Alerts when Zakat due |
| 💰 Zakat Calculator | Sums Zakatable assets, deducts non-Zakatable + qualifying debts. Niyyah column. Line-by-line breakdown |
| 🌐 Multi-Currency Converter | AED, SAR, EGP, MYR, GBP, USD, PKR, INR, CAD. Live FX via GOOGLEFINANCE |
| 📈 Stocks Zakat | Intent toggle (Speculator/Dividend Investor) + Method (full balance-sheet OR 25% NZF-proxy) |
| 🗂️ Mutual Funds & ETFs | Separate from stocks. Default 25% NZF-proxy. Per-fund details |
| 💰 Sukuk Tracker | By structure: Ijarah (rental), Musharakah (ownership), Murabahah (receivable). Auto-applies correct rule |
| 🏠 Rental Property Zakat | Annual rental net income calc. Multi-property |
| 🏚️ Property Resale & Land | Resale-intent properties/plots: full market value Zakatable. Long-term hold: not Zakatable |
| 🌾 Agricultural Zakat | 5%/10% on crops by irrigation method. Livestock counts |
| 🏦 EOSB & Provident Fund | Gulf-critical. DB/DC/SIPP detection. Voluntary vs. compulsory contributions. SIPP underlying analysis |
| 💎 Cryptocurrency | First-class line item. BTC/ETH/altcoins. Per-coin units, monthly price, wallet/exchange |
| ⏳ Qada Zakat (Missed Years) | Cumulative tracker for missed years. Per-year wealth, Zakat owed, paid status. Recovery payment plan |
| 🌙 Zakat al-Fitr Calculator | Separate obligation paid before Eid Salah. Per family member: 2.5kg staple food or local cash equivalent |
| 🤝 Distribution Tracker | 8 eligible categories per Surah At-Tawbah 9:60 (Fuqara, Masakin, Amileen, Mu'allafah Qulubuhum, Riqab, Gharimin, Fi Sabilillah, Ibn al-Sabil). 5-year history |
| 📅 Partial Payment Planner | Pay Zakat monthly. Monthly equivalent calc. Tracks contributions vs. obligation |
| 👨‍👩‍👧 Family Consolidation | Combine spouse + dependents. Per-person Nisab status. Joint vs. individual obligation |
| 🤖 AI Zakat Advisor | 8 AI prompts (see below) |

## AI Zakat Advisor — 8 Prompts (cite fatwas)
1. **Setup Wizard** — guided onboarding, Madhhab + scholar preferences
2. **Crypto/DeFi Zakat** — BTC, staked, liquidity pool guidance
3. **Nisab Method Picker** — gold vs. silver, pros/cons per scholar
4. **Stocks Method Picker** — speculator vs. dividend, full vs. 25% proxy (cites NZF + AAOIFI Standard 21)
5. **Pension Analyser** — DB/DC/SIPP detection, EOSB accessibility test
6. **Distribution Planner** — 8 categories with reasoning + verified org suggestions per category
7. **Qada Recovery Coach** — affordable plan to clear missed years
8. **Annual Report PDF** — formatted summary, incl. tax-deductible receipt (US/UK/CA)
