Three Things People Wish They'd Known on Day One
01
Setup order matters.
Net Worth pulls categories from Budget and balances from Debt Payoff. Set them up out of order and you'll re-enter the same data twice. Follow the order above and Setup-Wizard p. 2 explains why.
02
Input tabs only — never edit Dashboards.
Every spreadsheet has Input tab(s) and an Output Dashboard. Dashboards update automatically from Input tabs. If you "fix" a Dashboard cell directly, you break the formula. Edit Input tabs only.
03
First Saturday = sync day.
Set a recurring calendar slot — 15 min first Saturday of each month. Copy debt balances Debt → Net Worth, copy biz net profit Small Biz → Budget, update Sinking Funds balances. 30 seconds per spreadsheet. Done.
